# Dax Prajapati — Portfolio

A responsive portfolio website built for the mini-project assignment.

## Technologies
- HTML5
- Bootstrap 5
- CSS3
- JavaScript

## Files
- index.html — main webpage
- style.css — custom styling
- script.js — JavaScript interactions

## Important
The portfolio intentionally uses only the information supplied for Dax. Add any confirmed programming languages/technologies to the Skills section before submission.

## Run locally
Open `index.html` in a browser.

## Host with GitHub Pages
1. Create a GitHub account/repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open repository Settings → Pages.
4. Select the main branch and root folder.
5. Save and copy the generated live URL.
